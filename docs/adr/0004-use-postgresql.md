# ADR-0004: Использовать PostgreSQL

- Статус: proposed
- Дата: 2026-07-19

## Контекст

Заказы и резервирование требуют транзакционной модели и надёжного хранения состояния.

## Решение

Планировать PostgreSQL как основное транзакционное хранилище для сервисов, владеющих данными. Каждый сервис будет владеть своей логической областью данных; другие сервисы не будут выполнять прямые запросы к его таблицам или базе данных.

## Последствия

### Положительные последствия

- зрелые транзакции, индексы и инструменты эксплуатации;
- возможность реализовать outbox в той же транзакции.

### Отрицательные последствия

- необходимо явно разделять владение данными и миграции сервисов.

## Альтернативы

- единая общая база без границ владельцев;
- документное хранилище как основное состояние.
