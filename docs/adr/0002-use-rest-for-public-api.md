# ADR-0002: Использовать REST для публичного API

- Статус: proposed
- Дата: 2026-07-19

## Контекст

Внешнему клиенту нужен понятный и широко поддерживаемый интерфейс.

## Решение

Проектировать публичный API как REST поверх HTTP через будущий API Gateway.

## Последствия

### Положительные последствия

- привычная интеграция для клиентов и инструментов;
- возможность документировать интерфейс OpenAPI.

### Отрицательные последствия

- потребуется отдельно определить версионирование, ошибки и идемпотентность.

## Альтернативы

- публичный gRPC API;
- GraphQL.
