# ADR-0003: Использовать gRPC для внутреннего API

- Статус: proposed
- Дата: 2026-07-19

## Контекст

Будущим сервисам нужны типизированные внутренние синхронные вызовы.

## Решение

Проектировать внутренние синхронные контракты через gRPC и Protocol Buffers. Контракты должны быть явными, документируемыми и совместимо версионируемыми; вместе с первым клиентом будут определены таймауты, ошибки и политика повторов.

## Последствия

### Положительные последствия

- явные схемы сообщений и кодогенерация в следующих этапах;
- эффективная межсервисная коммуникация.

### Отрицательные последствия

- потребуется дисциплина совместимости контрактов и генерации кода.

## Альтернативы

- REST между сервисами;
- общая библиотека с прямыми вызовами.
