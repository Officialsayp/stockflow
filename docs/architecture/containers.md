# Контейнеры

## Статус

План; контейнеры не созданы.

## Предполагаемые контейнеры

- API Gateway как будущая HTTP-граница;
- Order Service для жизненного цикла заказов;
- Inventory Service для доступных и зарезервированных остатков;
- Notification Service для обработки событий и доставки уведомлений;
- будущие PostgreSQL, Kafka, Redis и observability-компоненты.

Выбор конкретных образов, портов, сетей и параметров развёртывания пока не сделан.
