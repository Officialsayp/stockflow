# Контекст системы

## Статус

Предполагаемая архитектура; не реализована.

## Контекст

StockFlow задуман как учебная платформа для обработки заказов и резервирования остатков. Внешний клиент будет обращаться к публичной HTTP-границе, а бизнес-сервисы будут изолировать ответственность за заказы, запасы и уведомления.

## Границы

На этом этапе отсутствуют клиенты, интеграции, контракты и хранилища. Этот документ описывает только направление будущего дизайна.
