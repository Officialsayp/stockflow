# Документация StockFlow

Здесь находится начальная, неисполняемая документация проекта. Она фиксирует предполагаемые границы и вопросы, которые будут уточняться по мере реализации.

- `architecture/` — обзор контекста, контейнеров, компонентов, целевых инвариантов и будущего развёртывания;
- `adr/` — короткие записи архитектурных решений;
- `diagrams/` — место для будущих диаграмм;
- `api/` — место для будущих описаний API;
- `runbooks/` — будущие операционные сценарии;
- `load-testing/` — будущие материалы нагрузочного тестирования.

Документы не подтверждают наличие работающих сервисов или инфраструктуры.
