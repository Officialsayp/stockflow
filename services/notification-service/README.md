# Notification Service

## Ответственность

Будущая обработка доменных событий и доставка уведомлений через выделенные каналы или провайдеры.

## Не должен делать

- не изменяет состояние заказов или остатков;
- не принимает решения о резервировании;
- не является источником истины для доменных данных других сервисов;
- не публикует публичный HTTP API без отдельного решения.

## Предполагаемые входные интерфейсы

Будущие сообщения из Kafka и при необходимости внутренние управляющие контракты. Входящие события и их схемы пока не определены.

## Предполагаемые исходящие зависимости

Будущие адаптеры доставки и собственное транзакционное хранилище для попыток доставки и DLQ. Реальные брокеры, провайдеры и БД отсутствуют.

## Предполагаемые данные

Попытки доставки, результаты обработки, дедупликационные данные и будущие записи DLQ. Схема и миграции отсутствуют.

## Статус

**Not implemented.**
