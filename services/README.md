# Services

Каталог задаёт границы будущих сервисов StockFlow. В нём нет Go-модулей, исходного кода, миграций или сгенерированных контрактов.

| Сервис | Предполагаемая ответственность | Статус |
| --- | --- | --- |
| `api-gateway` | внешняя HTTP-граница | Not implemented |
| `order-service` | заказы и координация резервирования | Not implemented |
| `inventory-service` | остатки и резервирование | Not implemented |
| `notification-service` | обработка событий и уведомления | Not implemented |

Каждый сервис должен владеть своей предметной областью и не импортировать внутренности другого сервиса.
