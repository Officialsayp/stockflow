# API Gateway

## Ответственность

Будущая внешняя HTTP-граница StockFlow: маршрутизация публичных запросов, единообразная обработка ошибок, корреляция запросов и применение общих политик на границе.

## Не должен делать

- не владеет бизнес-состоянием заказов или остатков;
- не принимает решения о резервировании;
- не реализует доменную логику сервисов;
- не хранит постоянные данные предметной области.

## Предполагаемые входные интерфейсы

Публичный REST/HTTP API, который позже будет описан в `api/openapi`.

## Предполагаемые исходящие зависимости

Внутренние вызовы к `order-service` и `inventory-service` через согласованные контракты.
Конкретные протоколы, таймауты и политики повторов ещё не определены реализацией.

## Предполагаемые данные

Постоянного доменного хранилища не предполагается; возможны только краткоживущие технические данные, если это будет обосновано отдельно.
