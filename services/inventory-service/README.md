# Inventory Service

## Ответственность

Будущий владелец данных о товарных остатках и операциях резервирования.

## Не должен делать

- не управляет полным жизненным циклом заказа;
- не отвечает за внешнюю HTTP-границу;
- не отправляет пользовательские уведомления;
- не предоставляет внутренние структуры хранения другим сервисам.

## Предполагаемые входные интерфейсы

Внутренние gRPC-вызовы из `order-service` и другие будущие внутренние контракты. Внешние публичные методы не определены.

## Предполагаемые исходящие зависимости

Будущие транзакционное хранилище, кэш и публикация событий через outbox. Конкретные интеграции и схемы сообщений пока не добавлены.

## Предполагаемые данные

Доступные остатки, резервирования, ключи идемпотентности и будущие записи outbox. Миграции и модели данных отсутствуют.

## Статус

**Not implemented.**
