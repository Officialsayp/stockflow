# Security Policy

## Поддерживаемый статус

На bootstrap-этапе StockFlow не содержит развертываемого приложения или секретов. Политика будет уточняться по мере появления исполняемых компонентов.

## Сообщение об уязвимости

Не публикуйте подробности потенциальной уязвимости в публичном issue. Свяжитесь с владельцем репозитория приватно через GitHub и укажите затронутый компонент, условия воспроизведения и возможный эффект.

## Ожидания

Не предполагаются SLA или автоматические исправления до появления поддерживаемых релизов. Ответственные раскрытия и минимально необходимый контекст приветствуются.
