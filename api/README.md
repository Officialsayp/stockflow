# API contracts

Эта зона зарезервирована для будущих контрактов StockFlow.

- `proto/` — будущие внутренние gRPC/Protocol Buffers-контракты;
- `openapi/` — будущие спецификации публичного REST API;
- `events/` — будущие схемы доменных событий.

На bootstrap-этапе контракты и сгенерированный код намеренно отсутствуют. Добавление каждого контракта должно сопровождаться отдельным архитектурным решением и проверками совместимости.
